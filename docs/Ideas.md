## Tracks

The hackathon will have two tracks.

### Beginner

For participants who are new to AI safety or model evaluation.

Projects will use accessible tools and focus on questions such as instruction following, hidden instructions in context, model comparison, basic red teaming, and building simple evaluations.

No previous AI safety experience is required.

### Advanced

For participants with experience in machine learning, software engineering, security, or research.

Projects will involve more systematic model evaluations, prompt injection benchmarks, agent security, automated red teaming, and evaluation tooling.

Participants can move between tracks depending on their experience and project.

## Technical focus

The main technical theme is understanding how AI systems behave when instructions, data, and context interact in unexpected ways.

One example is a model given a normal task with additional instructions hidden inside the context. Another is an AI agent reading external content that contains instructions intended to manipulate its behaviour.

Rather than focusing on finding isolated jailbreaks, teams will try to measure these behaviours systematically and make their results reproducible.

## Expected project outputs

Depending on the track, projects may produce:

* A small evaluation dataset
* Red team report
* Model comparison
* Python script
* Evaluation benchmark
* Interactive demo
* Open source tool
* Research note
* Policy brief
* Educational resource
